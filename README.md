Getting Started
Since there is no way to read files currently, you will need a computer to get the App Hash/UUID.

Download Nugget on your computer and plug in your phone.
Then, navigate to the Settings page and click the Pocket Poster Helper button.
Inside Pocket Poster, click the Detect button inside of settings.

Community-made wallpapers can be found on the official Cowabun.ga site.
Join the Cowabunga Discord Server for additional help.
